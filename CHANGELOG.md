# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-16

### Added

- Initial release of Mini-SOC Platform
- NestJS Backend API with JWT/MFA authentication
- React Dashboard with real-time alerts via WebSocket
- RBAC with SOC-specific roles (L1, L2, L3, Threat Hunter, Incident Responder)
- Wazuh SIEM integration with custom rules and MITRE ATT&CK mapping
- Suricata NIDS with custom detection rules
- Zeek Network Security Monitoring
- Falco runtime container security
- YARA malware detection rules
- OpenSearch as SIEM data lake
- n8n SOAR with automated playbooks
- Threat Intelligence integration (VirusTotal, AbuseIPDB, MISP)
- TheHive & Cortex case management
- HashiCorp Vault secrets management
- Prometheus + Grafana monitoring stack
- Nginx reverse proxy with WAF and rate limiting
- Docker Compose deployment (dev + prod)
- Kubernetes manifests and Helm charts
- Terraform infrastructure as code
- Ansible automated deployment
- GitLab CI/CD and GitHub Actions pipelines
- DevSecOps security scanning (Trivy, Semgrep, TruffleHog)
- Automated backup and disaster recovery
- Complete documentation
- MITRE ATT&CK heatmap visualization
- Real-time risk score calculation
- Incident timeline and workflow management
- IOC management with auto-enrichment
- PDF report generation
- Sigma rules integration
